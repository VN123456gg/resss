# My portfolio

Generated with the Portfolio Builder. This is a static site — no build
step, no framework, ready to deploy as-is.

## Edit it later

Everything you typed (and your color/animation choices) lives in
**`data.js`**. Open it in any text editor to tweak content without
regenerating the whole site. `index.html`, `style.css`, and `script.js`
are the shared engine — you generally won't need to touch them.

## Preview locally

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Deploy to Vercel

**Dashboard:** push this folder to a GitHub repo → [vercel.com/new](https://vercel.com/new)
→ import the repo → framework preset **"Other"** (no build command needed) → Deploy.

**CLI:**
```bash
npm i -g vercel
cd this-folder
vercel
```
